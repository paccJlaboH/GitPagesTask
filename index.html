Система контролю версій Git

1. Вступ

Система контролю версій (VCS) — це програмне забезпечення, що відстежує зміни у файлах. Git — це розподілена система контролю версій, створена у 2005 році Лінусом Торвальдсом.

2. Основні переваги Git

  • Розподілена архітектура (робота офлайн)
  • Зручне створення гілок та об'єднання коду
  • Висока швидкість та безпека (SHA-1/SHA-256)

3. 10 базових команд Git

  1. git init — Ініціалізація локального репозиторію.
  2. git clone <URL> — Клонування віддаленого репозиторію.
  3. git status — Перегляд стану файлів.
  4. git add . — Додавання змін до індексу.
  5. git commit -m "опис" — Фіксація змін у репозиторії.
  6. git branch — Перегляд та управління гілками.
  7. git checkout -b <гілка> — Створення та перехід на нову гілку.
  8. git merge <гілка> — Об'єднання гілок.
  9. git pull — Отримання змін з віддаленого репозиторію.
  10. git push origin <гілка> — Надсилання змін на віддалений сервер.
